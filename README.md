# Melon

Английский с нуля: PWA на чистом HTML и JS, работает без интернета, прогресс хранится на телефоне.

- `js/course.js` — все уроки и диалоги
- `js/core.js` — проверка ответов, сборка упражнений, очки, повторение
- `js/app.js` — интерфейс
- `js/media.js` — разборы песен, кино и мемов. Текстов песен здесь нет: только официальный клип, отдельные слова и свои примеры
- `js/grammar.js` — правила и задания по грамматике
- `js/alternates.js` — другие верные ответы на перевод. Жалоба «мой ответ верный, а не засчитали» лечится здесь
- `js/games.js` — уровни игры «Слова» и раскладка сетки. Новые слова уровня добавлять только в конец `BASES`, номер уровня у игрока хранится числом
- `js/cloud.js`, `js/config.js` — связь с сервером; пока в конфиге пусто, аккаунтов нет
- `server/schema.sql` — сервер: выполнить целиком в Supabase → SQL Editor
- `sw.js` — офлайн. **После любого изменения файлов увеличь `VERSION`**, иначе телефоны не получат обновление. Новый файл добавь в `FILES`.
- `tools/make_icons.py` — иконки (нужен Pillow)

Проверки: `npm test` (сервер проверяется на настоящем Postgres в памяти).
Запуск: конфиг `melon-web` (порт 8768, как на сайте) или `melon-dev` (порт 8769, с локальным сервером и без офлайна).
На телефоне установка и офлайн работают только по HTTPS.
