# Melon

Английский с нуля: PWA на чистом HTML и JS, работает без интернета, прогресс хранится на телефоне.

- `js/course.js` — все уроки и диалоги
- `js/core.js` — проверка ответов, сборка упражнений, очки, повторение
- `js/app.js` — интерфейс
- `sw.js` — офлайн. **После любого изменения файлов увеличь `VERSION`**, иначе телефоны не получат обновление. Новый файл добавь в `FILES`.
- `tools/make_icons.py` — иконки (нужен Pillow)

Проверки: `npm test`. Запуск: конфиг `melon-web` (порт 8768) или любой статический сервер.
На телефоне установка и офлайн работают только по HTTPS.
